# Bypass compile check

Verifies your own code without waiting for A2's skeleton and without holding the Gradle lock. The trick is to use the **real 1.12.2 mapped jar**
as dependencies, plus a set of temporary stubs patching the cross-package symbols that haven't landed yet, compiled straight with `javac`.

```bash
tools/verify/verify_compile.sh src/main/java/com/hbm            # compile all of com/hbm
tools/verify/verify_compile.sh src/main/java/com/hbm/blocks     # compile the blocks package only
```

## About stubs/

Once `main` is merged into this branch, `src/main/java` holds the real A2/A4 classes and the stubs get cleaned up one by one.
**Measured (counting `tools/verify/stubs/*.java`, this round): 0** — `main` compiles standalone now,
No symbol patches are needed here anymore; if merging surfaces a missing piece someday, patch it temporarily on demand and delete it after use.

- **Not compiled by Gradle** (the path sits under `tools/`, not in `src/`), so it doesn't affect the mod build;
- Once the other side's real class lands in `main`, delete the matching stub — **a stale stub masks real problems**.
  This bit us once this round: a stub spelled `PollutionType` as `HEAVY_METAL` while the real one in main is `HEAVYMETAL`;
  So the first thing after merging main is deleting every stub that shares a name with a real class (11 deleted).
- The **authoritative check is the real Gradle build agreed in §10**; this is only a lock-free quick self-check bypass.

## Loot tables

- `check_loot_hardcode.py`: spot-checks the hardcoded drop hooks §15 forbids (`getItemDropped` / `quantityDropped` /
  `dropBlockAsItem`; the hit count should be 0), and it also reports the `setTable(` locations inside `LootTableLoadEvent`.
  Returns 1 on any hit, so it can be hung into the pre-merge self-check.
- The listing export lives in `tools/export_loot_tables.py` (which generates `docs/loot-tables.md`), not in this directory.

## Why a private jar copy

The mapped jar in the cache is generated by ForgeGradle, which deletes-then-writes when others run Gradle concurrently.
The script copies one to `/tmp/a3-jar/forge.jar` and prefers it, keeping the check from randomly failing once in a while.
